# 研发费用合规管理系统 - 数据库设计

## 1. 需求概述

### 1.1 权限三级架构

| 角色 | role值 | 权限说明 |
|------|--------|----------|
| 总管理员 | 1 | 最高权限，只能管理分公司账号（开启/新增/禁用） |
| 分公司管理员 | 2 | 所属分公司的所有操作 + 重启已结算项目 |
| 分公司员工 | 3 | 所属分公司的普通操作，不能重启已结算项目 |

### 1.2 核心功能模块

- 分公司管理
- 用户管理（登录、权限控制）
- 项目管理（创建、进行中、已结束、已结算）
- 人员管理
- 设备管理
- 打卡记录导入
- 操作日志

## 2. 表结构设计

### 2.1 分公司表 (branch)

```sql
CREATE TABLE branch (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '分公司ID',
    name        VARCHAR(100) NOT NULL COMMENT '分公司名称',
    code        VARCHAR(50) UNIQUE NOT NULL COMMENT '分公司编码',
    status      TINYINT DEFAULT 1 COMMENT '状态：1启用 0禁用',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) COMMENT '分公司表';
```

### 2.2 用户表 (user)

```sql
CREATE TABLE user (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    branch_id   BIGINT COMMENT '所属分公司ID',
    username    VARCHAR(50) UNIQUE NOT NULL COMMENT '用户名',
    password    VARCHAR(255) NOT NULL COMMENT '密码（BCrypt加密）',
    name        VARCHAR(50) NOT NULL COMMENT '真实姓名',
    role        TINYINT NOT NULL DEFAULT 3 COMMENT '角色：1总管理员 2分公司管理员 3员工',
    status      TINYINT DEFAULT 1 COMMENT '状态：1启用 0禁用',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE SET NULL
) COMMENT '用户表';
```

### 2.3 项目表 (project)

```sql
CREATE TABLE project (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '项目ID',
    branch_id    BIGINT NOT NULL COMMENT '所属分公司ID',
    name         VARCHAR(200) NOT NULL COMMENT '项目名称',
    description  TEXT COMMENT '项目描述',
    start_date   DATE COMMENT '开始日期',
    end_date     DATE COMMENT '结束日期',
    status       TINYINT DEFAULT 1 COMMENT '状态：1进行中 2已结束 3已结算',
    amount       DECIMAL(12,2) DEFAULT 0 COMMENT '结算金额',
    settlement_proof VARCHAR(500) COMMENT '结算凭证文件路径',
    create_user  BIGINT COMMENT '创建人ID',
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    settle_time  DATETIME COMMENT '结算时间',
    
    FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE CASCADE,
    FOREIGN KEY (create_user) REFERENCES user(id) ON DELETE SET NULL
) COMMENT '项目表';

-- 索引
CREATE INDEX idx_project_branch ON project(branch_id);
CREATE INDEX idx_project_status ON project(status);
```

### 2.4 人员表 (employee)

```sql
CREATE TABLE employee (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '员工ID',
    branch_id    BIGINT NOT NULL COMMENT '所属分公司ID',
    employee_id  VARCHAR(50) UNIQUE NOT NULL COMMENT '工号',
    name         VARCHAR(50) NOT NULL COMMENT '姓名',
    gender       VARCHAR(10) COMMENT '性别',
    phone        VARCHAR(20) COMMENT '手机号',
    position     VARCHAR(100) COMMENT '职位',
    employee_type VARCHAR(20) COMMENT '员工类型：正式/兼职/外包',
    entry_date   DATE COMMENT '入职日期',
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE CASCADE
) COMMENT '人员表';

CREATE INDEX idx_employee_branch ON employee(branch_id);
```

### 2.5 设备表 (device)

```sql
CREATE TABLE device (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '设备ID',
    branch_id       BIGINT NOT NULL COMMENT '所属分公司ID',
    device_id       VARCHAR(50) UNIQUE NOT NULL COMMENT '设备编号',
    name            VARCHAR(100) NOT NULL COMMENT '设备名称',
    model           VARCHAR(100) COMMENT '型号',
    depreciation_rate DECIMAL(10,2) DEFAULT 0 COMMENT '折旧单价(元/小时)',
    status          TINYINT DEFAULT 1 COMMENT '状态：1正常 2维修 3报废',
    purchase_date   DATE COMMENT '购买日期',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE CASCADE
) COMMENT '设备表';

CREATE INDEX idx_device_branch ON device(branch_id);
```

### 2.6 项目-人员关联表 (project_employee)

```sql
CREATE TABLE project_employee (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT,
    project_id   BIGINT NOT NULL,
    employee_id  BIGINT NOT NULL,
    role_in_project VARCHAR(50) COMMENT '项目角色',
    linked_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (project_id) REFERENCES project(id) ON DELETE CASCADE,
    FOREIGN KEY (employee_id) REFERENCES employee(id) ON DELETE CASCADE,
    UNIQUE KEY uk_project_employee (project_id, employee_id)
) COMMENT '项目人员关联表';
```

### 2.7 项目-设备关联表 (project_device)

```sql
CREATE TABLE project_device (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT,
    project_id   BIGINT NOT NULL,
    device_id    BIGINT NOT NULL,
    linked_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (project_id) REFERENCES project(id) ON DELETE CASCADE,
    FOREIGN KEY (device_id) REFERENCES device(id) ON DELETE CASCADE,
    UNIQUE KEY uk_project_device (project_id, device_id)
) COMMENT '项目设备关联表';
```

### 2.8 打卡记录表 (attendance)

```sql
CREATE TABLE attendance (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '打卡记录ID',
    branch_id    BIGINT NOT NULL COMMENT '所属分公司ID',
    employee_id  BIGINT NOT NULL COMMENT '员工ID',
    work_date    DATE NOT NULL COMMENT '工作日期',
    check_in     DATETIME COMMENT '上班打卡时间',
    check_out    DATETIME COMMENT '下班打卡时间',
    duration     DECIMAL(5,2) COMMENT '工作时长(小时)',
    source       VARCHAR(20) DEFAULT 'system' COMMENT '来源：system系统导入/manual手动录入',
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE CASCADE,
    FOREIGN KEY (employee_id) REFERENCES employee(id) ON DELETE CASCADE
) COMMENT '打卡记录表';

CREATE INDEX idx_attendance_date ON attendance(work_date);
CREATE INDEX idx_attendance_employee ON attendance(employee_id);
```

### 2.9 操作日志表 (operation_log)

```sql
CREATE TABLE operation_log (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '日志ID',
    user_id      BIGINT COMMENT '操作人ID',
    branch_id    BIGINT COMMENT '所属分公司ID',
    operation    VARCHAR(100) NOT NULL COMMENT '操作类型',
    content      VARCHAR(500) COMMENT '操作内容',
    ip_address   VARCHAR(50) COMMENT 'IP地址',
    create_time  DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE SET NULL,
    FOREIGN KEY (branch_id) REFERENCES branch(id) ON DELETE SET NULL
) COMMENT '操作日志表';

CREATE INDEX idx_log_time ON operation_log(create_time);
```

## 3. 权限控制逻辑

### 3.1 总管理员 (role=1)

- 权限：管理所有分公司账号
- 限制：不能做业务操作（创建项目、添加人员等）
- 查询：可以查看所有分公司数据

### 3.2 分公司管理员 (role=2)

- 权限：自己分公司的所有操作 + 重启已结算项目
- 特殊权限：可以将项目状态从"已结算"改回"已结束"

### 3.3 分公司员工 (role=3)

- 权限：自己分公司的普通操作
- 限制：不能重启已结算项目

## 4. API 设计思路

### 4.1 登录接口

```
POST /api/login
Body: { username, password }
Return: { token, userInfo: { id, name, role, branchId } }
```

### 4.2 权限校验

- 使用 Sa-Token 鉴权
- 登录后 token 存 header：`Authorization: Bearer <token>`
- 后端通过拦截器获取用户角色和分公司ID

### 4.3 核心接口

| 模块 | 接口 |
|------|------|
| 登录 | POST /login, POST /login/admin |
| 分公司 | GET /branch/list, POST /branch, PUT /branch/{id}/status |
| 用户 | GET /user/list, POST /user, PUT /user/{id}, DELETE /user/{id} |
| 项目 | CRUD + 重启结算 PUT /project/{id}/restart-settle |
| 人员/设备/打卡 | 标准 CRUD |
